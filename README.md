# LAST LIGHT｜僵尸街区生存原型

这是一个低多边形第一人称僵尸生存网页原型。城市、枪械、刀具、敌人和音效均在运行时生成，Three.js 运行库已放入项目内部，不依赖旧仓库的图片或 CDN。

## 运行方式

直接用桌面浏览器打开 `index.html`，或在项目目录运行：

```bash
python -m http.server 5189
```

然后访问 `http://127.0.0.1:5189/index.html`。

正常模式点击开始后捕获鼠标；按 `Esc` 释放鼠标并暂停，再点击画面继续。内置预览不支持鼠标锁定时，会自动使用普通鼠标位移作为转向输入。

## 操作说明

| 按键 | 功能 |

| `W A S D` | 移动 |

## 游戏内容

- 三轮僵尸波次，共 30 个感染者。
- 自制轻量化城市街区、十字道路、建筑、窗户、路灯和掩体。
- 手枪、步枪、战术刀和手雷四个装备槽位。
- 枪械后坐力、换弹、开镜、击中反馈和刀具攻击。
- 跳跃、二段跳、蹲下、冲刺和鼠标视角控制。
- 渲染分辨率动态缩放、较低设备像素比和多重采样，关闭静态场景阴影以降低卡顿。

## 文件说明

```text
index.html              可直接运行的游戏页面
zombie-mode.js          僵尸模式、城市、刀具和武器槽位功能
vendor/three.min.js     本地 Three.js r128 运行库
index.original.html     基础版本源码，供补丁脚本使用
scripts/                生成和更新页面的脚本
tools/                  开发测试工具，不会被游戏页面自动加载
改造说明.md             本项目改造记录
```

项目不再包含旧版 `og.jpg` 和 `screenshots` 图片。除 `vendor/three.min.js` 外，没有需要额外下载的模型或贴图资源，武器与场景均为程序生成。
